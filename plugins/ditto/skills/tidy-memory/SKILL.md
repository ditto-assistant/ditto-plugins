# Tidy memory

Memory is only useful if it is current. Over months, the same fact gets saved
three ways, plans become decisions, decisions get reversed, and a launch date
moves twice. This skill keeps one topic's memory clean.

Use the bundled `ditto-memory` skill for connection, recall and capture rules.

## Scope it

Ask which topic, project, person or time range to tidy, and which space (main
memory, a project space or a company space). Work on one bounded topic per pass.
Never sweep the whole account unprompted.

## Survey

Search the topic, explore the related subjects and memory network, and fetch the
full memories you will judge. Use counts from the tools when they exist; a page
of search hits is not a total. Group what you find into:

- **Duplicates:** the same fact saved more than once.
- **Superseded:** an older fact a newer one replaces (a moved date, a reversed
  decision, a changed owner).
- **Contradictions:** two records that cannot both be true, with no clear winner.
- **Stale:** a status that was true once ("in progress", "waiting on legal") and
  probably is not now.
- **Mislabelled:** a proposal recorded as a decision, a draft recorded as sent.

Note each record's author and date. Content another person published to a space
the user subscribes to is not the user's to edit.

## Propose, then change

Show the user a short table: what you found, the proposed action (merge into one
record, update, mark superseded, or leave), and the evidence. Ask about every
contradiction rather than choosing a winner. Apply only the approved changes,
preferring an update to the record the user maintains over creating a new one.
Delete only when the user explicitly asks for deletion of that record. Check
each write's receipt.

## Report

Say what changed, what was left alone and why, and what still needs a human
answer. Offer to repeat the pass on a schedule with a Ditto workflow that asks
before changing anything; set it up only on the user's yes.
