# Gift ideas

The best gifts show you were paying attention. Ditto remembers the details: the
hobby a friend mentioned, the book a parent wanted, what you gave last year.

Use the bundled `ditto-memory` skill for connection, recall and capture rules.

## Recall the person

Ask who the gift is for, the occasion, the budget and the deadline. Search Ditto
for that person: interests, recent life events, things they said they wanted or
loved, sizes or preferences, and gifts already given. Fetch the memories you
use. Treat these as the user's own notes about someone else: use them only to
help the user, and keep them out of public searches and anything shared.

## Suggest

Offer three to five ideas across types (an object, an experience, something
handmade or personal), each with:

- why it fits this person, tied to a specific remembered detail;
- a price range and where to find it, verified with a current search;
- lead time, so it arrives in time.

Avoid repeating past gifts and anything the memory says they dislike. If memory
is thin, ask two or three questions about the person rather than guessing.

## Remember

Offer to save the choice, the occasion and the date, so next year's suggestions
avoid repeats. Offer to save new details the user mentions ("she's learning
pottery now"). Buy only when the user asks and a connected tool supports it,
confirming the item and total first.

Offer a Ditto workflow that reminds the user a couple of weeks before important
dates with fresh ideas. Set it up only on the user's yes.
